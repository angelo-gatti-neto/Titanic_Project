# 🚢 Titanic: Machine Learning from Disaster

Este projeto utiliza aprendizado de máquina para prever a sobrevivência de passageiros do Titanic com base em características como idade, sexo, classe social e local de embarque.

## 📚 Sobre o Projeto

Participação no desafio "Titanic: Machine Learning from Disaster" do Kaggle, aplicando técnicas de Análise Exploratória de Dados (EDA), Feature Engineering e Modelagem Preditiva.

## 📊 Tecnologias Utilizadas

- Python 3.10
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🛠️ Etapas do Projeto

- Entendimento dos dados
- Tratamento de valores ausentes
- Análise Exploratória de Dados (EDA)
- Engenharia de features
- Treinamento de modelo de Machine Learning (Random Forest Classifier)
- Submissão de previsões no Kaggle

## 🎯 Resultado

- Acurácia obtida nos dados de validação: **82.68%**
- Primeira submissão realizada no Kaggle
